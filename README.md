### 🧪 Proyectos Destacados de QA

#### 🚕 1. [Urban Routes - Automatización Web E2E (Selenium + POM)](https://github.com/MarcelIvan-tech/qa-project-Urban-Routes-es)
* **Descripción:** Suite completa de pruebas automatizadas End-to-End para el flujo crítico de reserva de taxis.
* **Aspectos Técnicos:** Implementación del patrón **Page Object Model (POM)**, esperas explícitas con `WebDriverWait`, y extracción dinámica del código de confirmación SMS inspeccionando logs de red/performance del navegador.
* **Stack:** `Python`, `Selenium WebDriver`, `Pytest`.

#### 🛒 2. [Urban Grocers - API Testing Automatizado](https://github.com/MarcelIvan-tech/Proyecto_Urban_Grocers_app_QA)
* **Descripción:** Validación integral de la API REST de Urban Grocers para la gestión y creación de kits de usuario.
* **Aspectos Técnicos:** Cobertura de pruebas para escenarios positivos y negativos sobre el parámetro `name`, validación de tokens de autorización (`authToken`), códigos de estado HTTP y análisis de esquemas de respuesta JSON.
* **Stack:** `Python`, `Requests`, `Pytest`.

#### 📋 3. [Control de Calidad & Pruebas Manuales - Urban Routes](https://github.com/MarcelIvan-tech/Proyecto_Control_de_Calidad_Urban_Routes)
* **Descripción:** Diseño y ejecución de estrategias de prueba para la interfaz web y cálculo de tarifas de viaje.
* **Aspectos Técnicos:** Análisis de requerimientos funcionales y zonas grises, diseño de casos de prueba con valores límite (BVA), clases de equivalencia, diagramas de flujo y matrices de compatibilidad entre navegadores (Chrome y Firefox).
