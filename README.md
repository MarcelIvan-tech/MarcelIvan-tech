### 🧪 Proyectos Destacados de QA

#### 🚕 1. [Urban Routes - Automatización Web E2E (Selenium + POM)](https://github.com/MarcelIvan-tech/qa-project-Urban-Routes-es)
* **Objetivo:** Suite completa de pruebas automatizadas End-to-End para el flujo crítico de reserva de taxis.
* **Enfoque Técnico:** Arquitectura limpia con **Page Object Model (POM)**, esperas explícitas con `WebDriverWait`, y extracción dinámica de códigos SMS interceptando logs de performance del navegador.
* **Stack:** `Python` · `Selenium WebDriver` · `Pytest` · `PyCharm`

#### 🛒 2. [Urban Grocers - API Testing Automatizado](https://github.com/MarcelIvan-tech/Proyecto_Urban_Grocers_app_QA)
* **Objetivo:** Validación integral de la API REST de Urban Grocers para la gestión y creación de kits de usuario.
* **Enfoque Técnico:** Pruebas automatizadas de parámetros límite sobre el campo `name`, validación de tokens de sesión (`authToken`), aserciones de esquemas JSON y códigos de estado HTTP (200, 201, 400).
* **Stack:** `Python` · `Requests` · `Pytest`

#### 📋 3. [Control de Calidad & Pruebas Manuales - Urban Routes](https://github.com/MarcelIvan-tech/Proyecto_Control_de_Calidad_Urban_Routes)
* **Objetivo:** Diseño y ejecución de estrategias de prueba para la interfaz web y lógica de tarifas.
* **Enfoque Técnico:** Detección de zonas grises en requerimientos, diseño de matrices de prueba con valores límite (BVA) y clases de equivalencia, diagramas de flujo y pruebas cross-browser (Chrome y Firefox).
* **Stack:** `Análisis de Requerimientos` · `Test Cases` · `Bug Reports` · `Jira Format`
